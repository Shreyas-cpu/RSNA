# Plan 02-01: Leakage-Free Stratified Group Validation & Exact Macro AUC Harness

## Objective
Establish a mathematically sound 5-Fold Stratified Group K-Fold splitting scheme and an exact Macro-averaged ROC AUC metric evaluation engine across all 12 knee abnormality classes with per-class breakdown tracking (D-07, D-08, D-09).

<action>
Create src/evaluation/__init__.py and src/evaluation/split.py addressing D-07:
1. Define DEFAULT_TARGET_COLS with the 12 canonical knee abnormality labels:
   ['acl', 'pcl', 'mcl', 'lcl', 'medial_meniscus', 'lateral_meniscus',
    'patellar_tendon', 'quadriceps_tendon', 'cartilage_femur',
    'cartilage_tibia', 'cartilage_patella', 'joint_effusion'].
2. Implement create_stratified_group_folds(df, group_col='StudyInstanceUID', target_cols=None, n_splits=5, seed=42):
   - Deduplicate or group by group_col to study-level representations.
   - Perform multi-label stratified partitioning across n_splits.
   - Assign a 'fold' column (0 to n_splits - 1) to each row in df.
3. Implement verify_leak_free_split(df, fold_col='fold', group_col='StudyInstanceUID') -> bool:
   - Check pairwise intersection of group_col values across all fold pairs.
   - Assert intersection is empty, returning True (or raising ValueError if leak detected).
4. Create tests/test_split.py verifying zero study leakage and balanced fold distributions.

<action>
Create src/evaluation/metrics.py addressing D-08 and D-09:
1. Implement compute_multilabel_auc_dict(y_true, y_pred, class_names=None) -> Dict[str, float]:
   - Accepts 2D numpy arrays or PyTorch tensors of ground truth binary labels and continuous predicted probabilities.
   - Computes roc_auc_score for each class column independently.
   - Gracefully handles single-class edge cases (returning NaN or 0.5 without raising unhandled errors).
2. Implement compute_macro_auc(y_true, y_pred, class_names=None) -> float:
   - Computes unweighted arithmetic mean over valid class AUC scores.
3. Implement MetricTracker class:
   - update(y_true_batch, y_pred_batch) accumulates batches across validation loop.
   - compute() returns dict with 'macro_auc' and per-class AUC scores.
   - generate_summary_report() returns formatted string / markdown table of results.
4. Create tests/test_metrics.py testing perfect predictions (AUC=1.0), inverted predictions (AUC=0.0), random predictions (AUC~0.5), and single-class edge cases.
</action>
