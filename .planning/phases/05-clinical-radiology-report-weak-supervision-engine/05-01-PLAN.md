# Plan 05-01: Clinical Radiology Report Parser & LLM Extractor

## Objective
Implement the narrative radiology NLP extraction engine to convert unstructured clinical impressions from `train.csv` into calibrated continuous pseudo-probabilities in $[0.0, 1.0]$ across all 12 target pathologies (D-17).

- tests/test_report_parser.py

</read_first>
<action>
Create src/nlp/__init__.py and src/nlp/report_parser.py addressing D-17:
1. Define PATHOLOGY_VOCABULARY for all 12 target classes:
   - Targets: ACL, MCL, Medial Meniscus, Lateral Meniscus, Medial OA, Lateral OA, PF OA, Effusion, Synovitis, Baker's, Contusion, Fracture.
   - For each class, specify anatomical keyword patterns, positive abnormality tokens (tear, sprain, fracture, effusion), and negative/normal tokens (intact, normal, unremarkable).
2. Implement NegEx syntactic scoping:
   - Split report text into sentences and clinical clauses.
   - Match pre-negations ("no evidence of", "negative for", "without", "no") and post-negations ("is intact", "unremarkable", "preserved", "shows no tear").
3. Assign calibrated certainty scores:
   - Definitive positive: ~0.95
   - Probable / moderate: ~0.75
   - Equivocal / possible: ~0.50
   - Unmentioned / prior: ~0.10
   - Definitive negative: ~0.05
4. Implement parse_report(text: str) -> Dict[str, float] returning calibrated probabilities for all 12 classes.
5. Create tests/test_report_parser.py validating negation handling, certainty distinctions, and output ranges.
</action>
<acceptance_criteria>

- Negation correctly sets negative certainty (~0.05) rather than false positive
</acceptance_criteria>
<verify>

  <fails_when>non-zero exit code or any test fails</fails_when>
</verify>
<done>
Deterministic clinical report NegEx parser accurately identifies positive findings, respects negation scoping, and assigns calibrated probabilities across all 12 classes.
