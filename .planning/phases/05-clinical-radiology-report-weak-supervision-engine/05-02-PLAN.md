# Plan 05-02: Ground-Truth Alignment Validation & Silver Dataset Generation

## Objective
Implement `WeakLabelValidator` to benchmark extracted pseudo-labels against the human-labeled subset of `train.csv`, evaluate multi-label alignment (ROC AUC, correlation), and generate `silver_train.csv` with certainty-weighted samples for downstream visual model pretraining (D-18).

<action>
Create src/nlp/validator.py addressing D-18:
1. Implement WeakLabelValidator:
   - evaluate_alignment(df, report_col='Report', target_cols=None) -> Dict[str, Any]:
     - Filters studies with non-null ground truth labels and non-null reports.
     - Extracts pseudo-probabilities using ClinicalReportParser.
     - Computes per-class and Macro ROC AUC against ground truth.
     - Computes Pearson correlation and F1 at threshold 0.5.
     - Returns summary dictionary with overall macro_auc, mean_correlation, and per-class metrics.
   - generate_silver_dataset(df, report_col='Report', target_cols=None, output_path=None, min_certainty=0.1) -> pd.DataFrame:
     - Iterates through unannotated (or all) studies with reports.
     - Extracts 12-class pseudo-probabilities.
     - Computes sample certainty weight: $w_i = \frac{1}{12} \sum_{c=1}^{12} 2 \cdot |p_{ic} - 0.5|$.
     - Filters out reports with low certainty (< min_certainty).
     - Saves to `silver_train.csv` if output_path specified.
2. Create tests/test_weak_validator.py verifying:
   - evaluate_alignment computes valid ROC AUC and correlation on synthetic ground truth.
   - generate_silver_dataset produces valid columns, bounded weights, and expected row counts.
</action>
