# Plan 03-01: 2D Vision Backbone Feature Extractor

## Objective
Implement a modular 2D slice feature extractor wrapping `timm` vision backbones that processes multi-channel 2.5D slabs and outputs sequence feature representations for attention aggregation (D-10).

<action>
Create src/models/__init__.py and src/models/backbone.py addressing D-10:
1. Define SliceBackbone(nn.Module) accepting model_name='resnet34d' (default lightweight for fast tests), pretrained=False/True, in_chans=3, drop_rate=0.0.
2. Initialize timm model via timm.create_model(model_name, pretrained=pretrained, num_classes=0, in_chans=in_chans, drop_rate=drop_rate).
3. Determine feature_dim dynamically from model.num_features.
4. Implement forward(x):
   - Accepts 5D tensor (B, S, C, H, W) or 4D tensor (N, C, H, W).
   - If 5D: folds B and S into batch dimension (B * S, C, H, W), passes through backbone, unfolds back to (B, S, D).
   - If 4D: passes directly to backbone returning (N, D).
5. Expose out_features / feature_dim attribute for downstream pooling layers.
</action>
