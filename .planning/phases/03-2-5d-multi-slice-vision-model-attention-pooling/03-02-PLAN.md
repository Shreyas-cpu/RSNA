<action>
Create src/models/attention.py addressing D-11:
1. Define GatedAttentionPool(nn.Module) with in_features, hidden_features=128:
   - Linear projection V: in_features -> hidden_features (tanh branch).
   - Linear projection U: in_features -> hidden_features (sigmoid branch).
   - Linear projection w: hidden_features -> 1.
2. Implement forward(x, mask=None):
   - Input shape: (B, S, D).
   - Compute gated score: A = w(tanh(V(x)) * sigmoid(U(x))) -> shape (B, S, 1).
   - If mask is provided: apply large negative value (-1e9) to masked positions.
   - Compute normalized attention weights: weights = softmax(A, dim=1) -> shape (B, S, 1).
   - Compute pooled representation: pooled = sum(weights * x, dim=1) -> shape (B, D).
   - Return (pooled, weights).
3. Create tests/test_attention.py verifying output shapes, weights summing to 1.0 along slice dimension, and gradient propagation.
</action>
<acceptance_criteria>

</acceptance_criteria>

</verify>

GatedAttentionPool computes mathematically valid attention distributions and collapses slice sequences to fixed study vectors.
