Create src/models/multi_plane.py addressing D-19:
1. Implement MultiPlaneFusion(feature_dim, num_planes=3, num_heads=4, dropout=0.1):
   - Learnable plane positional embeddings for ['sagittal', 'coronal', 'axial'].
   - Cross-plane multi-head self-attention layer.
   - Gated projection / LayerNorm combining plane embeddings into fixed study representation.
   - Masking support when a plane is absent from a study.
2. Implement MultiPlaneKneeModel:
   - Shared SliceBackbone (or optional plane-specific backbones).
   - Dedicated GatedAttentionPool per plane.
   - MultiPlaneFusion aggregating the 3 plane vectors.
   - Linear multi-label classification head projecting to num_classes (default 12).
   - forward(plane_dict, return_attention=False): accepts dict mapping plane names ('sagittal', 'coronal', 'axial') to (B, S_p, 3, H, W) tensors.
   - predict_proba(plane_dict) -> np.ndarray: returns continuous probabilities in [0.0, 1.0].
3. Update src/models/__init__.py to export MultiPlaneFusion and MultiPlaneKneeModel.
4. Create tests/test_multi_plane.py:
   - Verify forward pass shape (B, 12) and predict_proba bounds.
   - Verify missing plane robustness (e.g., omitting 'axial').
   - Verify backward pass and gradient flow through all planes.
