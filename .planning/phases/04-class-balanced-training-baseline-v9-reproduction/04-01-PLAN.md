# Plan 04-01: Class-Balanced Loss & Mixed-Precision AMP Trainer

## Objective
Implement dynamic positive-class weighting to mitigate multi-label class imbalance and build the mixed-precision `Trainer` pipeline with gradient accumulation, AdamW optimizer, and checkpoint management (D-14, D-15).

<action>
Create src/training/__init__.py and src/training/loss.py addressing D-14:
1. Implement compute_pos_weights(df_or_array, target_cols=None, clip_range=(1.0, 10.0)) -> torch.Tensor:
   - Computes positive and negative counts per column.
   - Applies square-root dampened ratio sqrt(N_neg / N_pos).
   - Clips weights into clip_range to prevent gradient instability on rare classes.
2. Implement create_loss_fn(pos_weights=None, label_smoothing=0.0):
   - Returns nn.BCEWithLogitsLoss configured with pos_weight tensor.
3. Create tests/test_loss.py:
   - Verify compute_pos_weights produces higher weights for rare classes.
   - Verify loss calculation matches expected values and backward gradients flow properly.
</action>

Create src/training/trainer.py addressing D-15:

   - Accepts model, optimizer, criterion, scheduler=None, device='cuda'/'cpu', use_amp=True, accumulation_steps=1, checkpoint_dir='checkpoints'.
   - train_epoch(train_loader): iterates batches, applies AMP autocast, scales loss, unscales for gradient clipping, steps optimizer every accumulation_steps, returns average train loss.
