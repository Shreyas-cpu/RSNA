# Plan 01-02: 2.5D Slab Extractor & PyTorch Dataset Cache Engine

## Objective
Implement tissue windowing, intensity scaling, and 2.5D 3-channel contiguous slab extraction, along with a high-throughput PyTorch `Dataset` that caches slabs locally to eliminate I/O bottlenecks during deep learning training.

<task id="01-02-01">
<title>Implement 2.5D slab extractor and tissue windowing</title>
<read_first>
- src/data/dicom_reader.py
- .planning/phases/01-fast-dicom-ingestion-slab-caching-engine/01-RESEARCH.md
</read_first>
<action>
Create src/data/slab_extractor.py. Implement SlabExtractor class with apply_windowing(image, window_center, window_width), extract_slabs(volume_array, num_slabs=5), and resize_slab(slab, target_shape=(256, 256)):
1. Linear window mapping: [center - width/2, center + width/2] -> [0.0, 1.0] if tags present.
2. Dynamic percentile clipping (0.5th to 99.5th percentile) followed by min-max scaling to [0.0, 1.0] if tags missing.
3. Slice sampling: sample num_slabs equidistant center slices, extract contiguous triplets [i-1, i, i+1] clamped to volume bounds, stack to shape (3, H, W).
4. Bilinear resizing using cv2.resize to target dimensions.
</action>
